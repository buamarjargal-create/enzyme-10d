# 🧬 ENZYME 10D — Багийн сорилт (v3)

10D ангийн биологийн "Энзим" хичээлийн бодит цагийн платформ. Гадны сан шаардахгүй, зөвхөн Node.js 18+ хэрэгтэй.

## Ажиллуулах
```
cd ENZYME-10D
node server.js
```
Эхний удаа гарах **багшийн нууц үгийг** хадгална уу (Багшийн хуудас → Тохиргоо дотор солино).
- Сурагч: `/` — хичээлийн код `10D2026ENZYM`, нэрээ сонгоно
- Багш: `/teacher` · Проектор: `/projector` (багшаар нэвтэрсэн компьютер дээр)
- Нэг WiFi дээр байвал сурагчид Багшийн хуудсан дээрх QR / холбоосоор орно. Интернетээс орох бол доорх "Байршуулах" хэсгийг үз.

## Хичээлийн явц (4 шат, ≈14 мин)
1. **Team vs Team** — Q1–Q6, хүн бүр хувиараа хариулна (+10). Баг олонх нь зөв бол багийн бонус.
2. **Peer Check** — нэг багийн бичсэн хариуг өөр баг ✅ Зөв / 🟡 Хэсэгчлэн / ❌ Буруу гэж үнэлнэ (өөрийгөө шалгахгүй). Үнэлгээ зөв бол +10, ойролцоо бол +5.
3. **Enzyme Duel** — баг бүр нэг асуулт: эхлээд хувиараа → 30 сек хэлэлцэнэ → нэг хариулт түгжинэ. Зөв бол +20.
4. **Save Your Team** — баг бүрийн хамгийн сул сэдвээс сүүлийн асуулт. Хамтдаа нэг хариулт, зөв бол +20.

Оноо: Зөв хариулт +10 · Peer Check +10/+5 · Багийн зөв хариулт +20 (Тохиргооноос өөрчилнө).

## Онцлог
- Баг бүрийн **хувийн чат** (зөвхөн тухайн баг харна); багш бүх багийн чатыг хажуугийн самбараас харна, бичиж, устгана.
- Хүлээлгийн дэлгэц: хөөрхөн наалт зураг, үгс.
- Үр дүнг диаграмаар харуулна (тархалт, сэдвээр, шатаар).
- Багш: түр зогсоох, цаг нэмэх, түгжих, шат руу үсрэх, асуулт засах, CSV татах, нөөцлөх/сэргээх.

## Байршуулах (хэн ч хэзээ ч орох сайт)
`render.yaml` бэлэн. GitHub-д оруулаад Render дээр Web Service үүсгэнэ. Өгөгдөл хадгалахад Disk (Starter төлөвлөгөө) хэрэгтэй; үнэгүй төлөвлөгөөнд сервер унтарч, өгөгдөл арилж болно. `SITE_URL`, `TEACHER_PASSWORD` орчны хувьсагчийг тохируулна. Google хайлтад гарах нь баталгаагүй (Search Console-д бүртгэнэ).
