# Сайтыг интернетэд гаргах (Terminal хэрэггүй)

## 1. GitHub (5 мин)
1. github.com дээр бүртгүүлнэ → **New repository** → нэр: `enzyme-10d` → **Private** → Create.
2. "uploading an existing file" холбоос дээр дарж, энэ хавтас доторх **бүх файлыг** чирж оруулна (`ENZYME-10D` хавтаст биш, доторх файлууд: server.js, public, lib, package.json, render.yaml гэх мэт). **Commit changes** дарна.

## 2. Render (5 мин)
1. render.com → GitHub-аар нэвтэрнэ → **New + → Blueprint** → `enzyme-10d` repo сонгоно.
2. Асуусан хоёр хувьсагчид: `TEACHER_PASSWORD` = өөрийн нууц үг (урт, хэнд ч хэлэхгүй), `SITE_URL` = хоосон орхиж болно (дараа нь Render-ийн өгсөн `https://….onrender.com` хаягаа бичнэ).
3. **Apply** дарна. 2–3 минутад бэлэн болно. Гарсан хаяг дээр сурагчид шууд орно.

## 3. Хаягаа бэлдэх
- Сурагч: `https://…onrender.com` (код 10D2026ENZYM)
- Багш: `…/teacher` — нэр `AmarjargalBuyanbaatar`, нууц үг = таны TEACHER_PASSWORD
- Дараа нь Render → Environment дээр `SITE_URL`-д хаягаа бичвэл QR зөв гарна.

## 4. Үнэгүй хувилбарын тухай (анхаарах)
- 15 минут хэн ч ороогүй бол унтарна, дараагийн удаа ~1 минут сэрнэ. Хичээлээс 5 минутын өмнө нэг орж сэрээгээрэй. **uptimerobot.com** (үнэгүй) дээр хаягаа 5 минут тутамд шалгуулбал унтахгүй.
- Үнэгүй хувилбар дээр сервер дахин асахад өгөгдөл (оноо, чат) арилна. Багшийн нууц үг TEACHER_PASSWORD-оос дахин тогтоогдоно. Тогтвортой хадгалахыг хүсвэл `render-starter.yaml`-ийн нэрийг `render.yaml` болгож солино (~$7/сар).

## 5. Google-д гаргах
- Өөрийн домэйн (жишээ `enzyme10d.mn`) холбоход илүү хайгдахуйц болно: Render → Settings → Custom Domains.
- search.google.com/search-console → хаягаа нэмж, sitemap.xml илгээнэ.
- Google-д гарах, ямар байранд гарах нь **баталгаагүй**, хэдэн хоногоос хэдэн долоо хоног болно. Багшийн нэвтрэх хуудас (/teacher) хайлтад орохоор нээлттэй, проектор хаалттай. Нэвтэрсний дараах самбар нууц үгээр хамгаалагдсан.
